# vacancy-platform

A small job-vacancy platform built with **Next.js 16** (App Router), **React 19**,
**TypeScript**, and **Tailwind CSS v4**. Browse open positions, filter them, view
details, and post new vacancies.

## Features

- Browse vacancies with live search, employment-type filter, and a remote-only toggle
- Vacancy detail pages
- Post-a-vacancy form with server-side validation
- JSON REST API under `/api/vacancies`
- File-backed data store (seeded from `data/vacancies.seed.json` on first run)
- Unit tests for the filtering/validation logic (Vitest)

## Getting started

Requirements: Node.js 22+.

```bash
npm ci          # install dependencies
npm run dev     # start the dev server at http://localhost:3000
```

## Scripts

| Command             | Description                                   |
| ------------------- | --------------------------------------------- |
| `npm run dev`       | Start the development server (Turbopack)      |
| `npm run build`     | Production build (also runs typegen + tsc)    |
| `npm run start`     | Start the production server                   |
| `npm run lint`      | Run ESLint                                     |
| `npm run typecheck` | Type-check with `tsc --noEmit`                |
| `npm test`          | Run unit tests once (Vitest)                  |
| `npm run test:watch`| Run unit tests in watch mode                  |

> Note: `npm run typecheck` relies on Next.js route types that are generated by
> `next dev` or `next build`. Run a build first in a fresh checkout.

## API

| Method | Path                   | Description                                   |
| ------ | ---------------------- | --------------------------------------------- |
| GET    | `/api/vacancies`       | List vacancies. Query: `search`, `type`, `remote=true` |
| POST   | `/api/vacancies`       | Create a vacancy (JSON body, validated)       |
| GET    | `/api/vacancies/{id}`  | Fetch a single vacancy (404 if missing)       |

## Project structure

```
src/
  app/
    api/vacancies/         # REST route handlers
    vacancies/[id]/        # vacancy detail page
    post/                  # post-a-vacancy form
    page.tsx               # home / browse
  components/              # UI components
  lib/                     # types, data store, pure utils + tests
data/vacancies.seed.json   # committed seed data
```
